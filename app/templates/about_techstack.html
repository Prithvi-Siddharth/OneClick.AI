Our Technology Stack

Frontend

Built with HTML5, CSS3, and JavaScript for a responsive and interactive user experience. We use Jinja2 for dynamic templating and FontAwesome for iconography.

Backend

Powered by Python and the high-performance FastAPI framework. It handles asynchronous requests, data processing, and API endpoints with speed and reliability.

Database

We use TiDB (MySQL compatible) for scalable and consistent data storage, managed via SQLAlchemy ORM for efficient database interactions.

Cloud & Infrastructure

AWS S3 is utilized for secure and scalable storage of user datasets and trained machine learning models, ensuring high availability and durability. Amazon Bedrock is used for the AI chatbot. AWS Lambda is used for serverless cloud processing.

Machine Learning

Leveraging Scikit-Learn and Pandas for data manipulation, preprocessing, and training robust machine learning models ranging from regression to classification.
