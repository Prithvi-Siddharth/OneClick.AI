Logistic Regression

Overview

Logistic Regression is a statistical analysis method used to predict a data value based on prior observations of a dataset. Unlike Linear Regression which predicts a continuous number, Logistic Regression predicts a binary outcome (e.g., Yes/No, True/False, 0/1).

Layman Explanation:

Imagine you want to predict if an email is "Spam" or "Not Spam". Logistic regression draws a curve that separates these two groups. If the probability is greater than 50%, it's classified as Spam; otherwise, it's Not Spam.

Core Equation:
P(y=1|x) = 1 / (1 + e-(wx + b))
Key Hyperparameters:
  • C (Regularization): Controls the penalty strength. Smaller values specify stronger regularization to prevent overfitting.
  • Solver: The algorithm to use in the optimization problem (e.g., liblinear, saga).
  • Penalty: Specifies the norm used in the penalization (l1 or l2).

Linear Regression

Overview

Linear Regression is a linear approach for modeling the relationship between a scalar response and one or more explanatory variables (dependent and independent variables).

Layman Explanation:

Think of trying to predict the price of a house based on its size. You might notice that as size increases, price tends to increase. Linear regression finds the best-fitting straight line through the data points to predict the price for any given size.

Core Equation:
y = wx + b
Key Hyperparameters:
  • Fit Intercept: Whether to calculate the intercept for this model.
  • Normalize: If True, the regressors X will be normalized before regression.

Random Forest

Overview

Random Forest is an ensemble learning method that operates by constructing a multitude of decision trees at training time and outputting the class that is the mode of the classes (classification) or mean prediction (regression) of the individual trees.

Layman Explanation:

Imagine asking a question to a group of 100 experts. Each expert (Decision Tree) gives their answer. Random Forest combines everyone's answer to give a final, more accurate prediction. It avoids the errors that a single expert might make.

Core Concept:
Prediction = Mode (Classification) or Mean (Regression) of Trees
Key Hyperparameters:
  • n_estimators: The number of trees in the forest. More trees usually means better performance but slower code.
  • max_depth: The maximum depth of the tree. Controls complexity and overfitting.
  • min_samples_split: The minimum number of samples required to split an internal node.
{% endif %} {% if model and model.name == 'DecisionTree' %}

Decision Tree

Overview

A Decision Tree is a flowchart-like structure in which each internal node represents a "test" on an attribute (e.g. at coin flip comes up heads or tails), each branch represents the outcome of the test, and each leaf node represents a class label.

Layman Explanation:

It works like a game of "20 Questions". Does it have wings? Yes. Is it a bird? Yes. Is it an eagle? No. The algorithm asks a series of questions to narrow down the possibilities until it reaches a conclusion.

Core Concept:
Splitting based on Gini Impurity or Entropy
Key Hyperparameters:
  • Criterion: The function to measure the quality of a split (Gini or Entropy).
  • max_depth: The maximum depth of the tree.
  • min_samples_leaf: The minimum number of samples required to be at a leaf node.
{% endif %} {% if model and model.name == 'KNeighborsClassifier' %}

KNeighbors Classifier

Overview

K-Nearest Neighbors (KNN) Classifier is a simple, easy-to-understand, versatile, and powerful machine learning algorithm. It checks the class of its 'k' nearest neighbors and votes to decide its own class.

Layman Explanation:

Tell me who your neighbors are, and I'll tell you who you are. If you move into a neighborhood where most people love spicy food, it's likely you'll start enjoying it too. KNN checks who is closest to you to guess what you are.

Core Concept:
Distance (Euclidean) = √[ Σ(x_i - y_i)^2 ]
Key Hyperparameters:
  • n_neighbors: Number of neighbors to use by default.
  • weights: Weight function used in prediction (uniform or distance).
  • metric: The distance metric to use for the tree (e.g., minkowski, euclidean).
{% endif %} {% if model and model.name == 'KNeighborsRegressor' %}

KNeighbors Regressor

Overview

Regression based on k-nearest neighbors. The target is predicted by local interpolation of the targets associated of the nearest neighbors in the training set.

Layman Explanation:

If you want to guess the price of a house, look at the 5 closest houses. The average price of those 5 houses is a good guess for yours.

Core Concept:
y = (1/k) * Σ y_i
Key Hyperparameters:
  • n_neighbors: Number of neighbors to use.
  • weights: Weight function used in prediction.
  • metric: The distance metric to use.
{% endif %} {% if model and model.name == 'KMeans' %}

KMeans Clustering

Overview

KMeans is an unsupervised learning algorithm that groups similar data points together and discovers underlying patterns. It looks for a fixed number (k) of clusters in a dataset.

Layman Explanation:

Imagine you have a bag of mixed marbles (red, blue, green) but you're colorblind. KMeans helps you sort them into piles based on their size and weight, hoping that similar ones end up together.

Core Concept:
Minimize Inertia: Σ ||x_i - μ_j||^2
Key Hyperparameters:
  • n_clusters: The number of clusters to form as well as the number of centroids to generate.
  • init: Method for initialization (e.g., k-means++).
  • max_iter: Maximum number of iterations of the k-means algorithm for a single run.
{% endif %} {% if model and model.name == 'SVC' %}

Support Vector Classifier (SVC)

Overview

Support Vector Classification (SVC) fits the data you provide, returning a "best fit" hyperplane that divides, or categorizes, your data. From there, after getting the hyperplane, you can feed some features to your classifier to see what the "predicted" class is.

Layman Explanation:

Imagine you have red and blue balls on the ground. You want to put a stick between them to seal them off. SVC tries to find the best place to put the stick so it's as far away from the closest balls of both colors as possible.

Core Concept:
Maximize Margin = 2 / ||w||
Key Hyperparameters:
  • C (Regularization): Controls the trade-off between smooth decision boundary and classifying training points correctly.
  • kernel: Specifies the kernel type to be used in the algorithm (linear, poly, rbf, sigmoid).
  • gamma: Kernel coefficient for 'rbf', 'poly' and 'sigmoid'.
{% endif %} {% if model and model.name == 'SVR' %}

Support Vector Regressor (SVR)

Overview

Support Vector Regression (SVR) uses the same principle as the SVM for classification, with a few minor differences. In the case of regression, a margin of tolerance (epsilon) is set in approximation to the SVM which would have already requested from the problem: there is no penalty for errors as long as they are smaller than this epsilon.

Layman Explanation:

Instead of a strict line, imagine a tube. SVR tries to fit as many data points as possible inside this tube. Points inside the tube don't cost anything, but points outside do.

Core Concept:
y = w'φ(x) + b (subject to ε-insensitive loss)
Key Hyperparameters:
  • kernel: Specifies the kernel type.
  • C: Regularization parameter.
  • epsilon: Epsilon in the epsilon-SVR model. It specifies the epsilon-tube within which no penalty is associated.
{% endif %} {% if model and model.name == 'Lasso' %}

Lasso Regression (L1)

Overview

Lasso (Least Absolute Shrinkage and Selection Operator) is a regression analysis method that performs both variable selection and regularization in order to enhance the prediction accuracy and interpretability of the statistical model it produces.

Layman Explanation:

Imagine you have a backpack and you want to fill it with items that are most useful for a trip. Lasso forces you to choose only the absolute essentials and leave the rest behind (setting their weight to zero), making your backpack lighter and easier to manage.

Core Concept:
Minimize: RSS + λ * Σ|β_j|
Key Hyperparameters:
  • alpha: Constant that multiplies the L1 term. Defaults to 1.0.
  • fit_intercept: Whether to calculate the intercept for this model.
  • max_iter: The maximum number of iterations.
{% endif %} {% if model and model.name == 'Ridge' %}

Ridge Regression (L2)

Overview

Ridge Regression is a technique for analyzing multiple regression data that suffer from multicollinearity. By adding a degree of bias to the regression estimates, ridge regression reduces the standard errors.

Layman Explanation:

Unlike Lasso, which throws items out of the backpack, Ridge just makes everything a little bit smaller so you can fit more in. It doesn't eliminate variables completely but shrinks their influence to prevent any single one from dominating.

Core Concept:
Minimize: RSS + λ * Σ(β_j)^2
Key Hyperparameters:
  • alpha: Regularization strength; must be a positive float.
  • fit_intercept: Whether to calculate the intercept for this model.
  • solver: Solver to use in the computational routines.
